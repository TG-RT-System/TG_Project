# 1. Python命名规则
## 1.1 小蛇形命名法
- **格式**：全小写+下划线；
- **例子**：user_name；
- **适用**：
	- **函数**名；
	-  **变量**名：
		- 局部变量；
		- 函数参数；
	- **文件**（模块）名；

## 2. 驼峰命名法
- **格式**：首字母大写+其他小写；
- **例子**：UserName；
- **适用**：
	- **类**名；
	- **类型变量**名（TypeVar）；


## 3. 大蛇形命名法
- **格式**：全大写+下划线；
- **例子**：USER_NAME；
- **适用**：
	- **常量**名：
		- 全局变量；
		- 配置项；
	- **环境变**量名；

# 2. Python函数参数可变规则
# 2.1 函数的形参可变类型
传递引用，修改影响外部，如:
- 列表（list）
- 字典（dict）
- 集合（set）
- 字节数组（bytearray）
- 自定义类的实例:大多数自定义类的对象默认是可变的，除非显式限制（如使用 __slots__ 且禁止修改属性）。

## 2.2 函数的形参不变类型
传递值，修改不影响外部， 如:
- None
- 整数（int）
- 元组（tuple）
- 字符串（str）
- 布尔值（bool）
- 浮点数（float）
- 冻结集合（frozenset）

## 2.3 要求
函数的形参采用不可变类型，保证代码的稳定性。
